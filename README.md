# Relatório Financeiro — Experiência do Usuário no Power BI

Repositório destinado ao desafio da DIO de atualização de um
relatório financeiro com foco na experiência do usuário.

## Status

Planejado. A implementação e os arquivos finais serão
adicionados posteriormente.

## Objetivo

Aprimorar a organização visual e a navegação de um relatório
financeiro composto por três páginas, facilitando a leitura
e a exploração dos dados.

## Etapas previstas

- [ ] Revisar o posicionamento e alinhamento dos visuais.
- [ ] Ajustar o contraste entre elementos e fundo.
- [ ] Considerar proporção áurea e equilíbrio visual no layout.
- [ ] Organizar os visuais em seções relacionadas.
- [ ] Revisar os gráficos e criar uma matriz de descrição de vendas.
- [ ] Padronizar a estilização das páginas.
- [ ] Adaptar a segunda página conforme os ajustes da primeira.
- [ ] Inserir botões e menus de navegação nas três páginas.
- [ ] Configurar a aparência dos botões nos estados de interação.
- [ ] Testar a navegação e documentar as alterações.

## Entregáveis previstos

- Relatório atualizado no formato `.pbix`.
- Capturas das três páginas.
- Documentação das melhorias de layout e navegação.
